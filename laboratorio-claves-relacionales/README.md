# Clave a clave

Recurso educativo interactivo para explicar claves primarias (PK) y claves foráneas (FK) en bases de datos relacionales.

## Cómo abrirlo

Abre `index.html` con cualquier navegador moderno. No requiere instalación, conexión a internet, servidor local ni proceso de compilación.

## Incluye

- Comparación visual entre PK y FK.
- Explorador de una relación uno-a-muchos entre Clientes y Pedidos.
- Reto guiado de tres pasos con retroalimentación inmediata.
- Chequeo rápido de comprensión.
- Diseño adaptable a teléfono, tableta y escritorio.
- Navegación por teclado y respeto a la preferencia de movimiento reducido.

## Archivos

- `index.html`: estructura y contenido pedagógico.
- `styles.css`: diseño, animaciones y adaptación responsive.
- `app.js`: interacciones, actividades y sonidos opcionales.

## Restricciones técnicas

El recurso se desarrolló en Vanilla JS y no usa paquetes externos. Por ello no incluye un sistema de componentes, pruebas de interfaz automatizadas, analíticas, guardado de avance entre dispositivos ni un editor de esquemas avanzado.

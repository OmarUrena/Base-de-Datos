01 — DESCUBRE

Cada tabla necesita una identidad

Piensa en una tabla como una lista de personas. ¿Cómo distinguimos a dos personas que se llaman igual?

◆

LA IDENTIDAD

Clave primaria PK

Es la columna que identifica de manera única cada fila de una tabla.

  • ✓ No se repite
  • ✓ Nunca está vacía
  • ✓ Se recomienda una por tabla
☝

Como tu número de cédula: solo te pertenece a ti.

VS
↗

EL ENLACE

Clave foránea FK

Es una columna que apunta a la clave primaria de otra tabla.

  • ✓ Puede repetirse
  • ✓ Crea una relación
  • ✓ Evita datos huérfanos
☝

Como escribir tu cédula en una compra para saber que es tuya.

✦

Regla para recordarLa primaria dice ¿quién soy?. La foránea dice ¿con quién me relaciono?.

# Normaliza

Recurso interactivo y autónomo para enseñar normalización de bases de datos y las tres primeras formas normales.

## Uso

Abre `index.html` en un navegador moderno. No requiere conexión, instalación, servidor ni proceso de compilación.

## Recorrido didáctico

1. Diagnóstico de anomalías de actualización, inserción y eliminación.
2. Mapa conceptual de 1FN, 2FN y 3FN.
3. Transformación paso a paso de una tabla de pedidos.
4. Explorador de dependencias funcionales.
5. Reto final con cuatro situaciones y retroalimentación.

## Archivos

- `index.html`: contenido y estructura semántica.
- `styles.css`: sistema visual, responsive y estados interactivos.
- `app.js`: demostraciones, navegación del taller y evaluación.

## Alcance

El material se concentra en 1FN, 2FN y 3FN. No aborda BCNF, 4FN, 5FN ni optimización física, porque el objetivo es consolidar primero la lectura de dependencias funcionales y anomalías.

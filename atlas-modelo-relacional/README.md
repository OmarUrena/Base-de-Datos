# Atlas Relacional

Recurso interactivo para enseñar entidades, atributos, relaciones, cardinalidad y fundamentos del modelo relacional.

## Uso

Abre `index.html` en un navegador moderno. Funciona sin conexión, instalación, servidor ni proceso de compilación.

## Recorrido

1. Explorador de entidades, atributos, relaciones y cardinalidad.
2. Anatomía interactiva de una relación: tabla, tupla, atributo y dominio.
3. Comparador de relaciones 1:1, 1:N y N:M.
4. Reglas para traducir un modelo conceptual a tablas.
5. Laboratorio guiado para construir el esquema de una clínica veterinaria.

El recurso también introduce claves primarias, claves foráneas, restricciones de integridad y opcionalidad.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css`: sistema visual y adaptación responsive.
- `app.js`: exploradores, demostraciones y laboratorio final.
